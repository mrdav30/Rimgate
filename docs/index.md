# Rimgate

Rimgate: Ancient Legacy is a Stargate-inspired RimWorld mod about ancient gate
networks, alien biotech, faction conflict and high-tier technology.

## Play and explore

Start with the [guides](guides/index.md), check the
[requirements and compatibility](guides/compatibility-matrix.md), then follow the
[Gate Network Guide](guides/gate-network-guide.md) for dialing, exploration and iris defense.
The [research guide](guides/research-and-progression.md) connects the unlocks.

## Develop and extend

The [contributor guide](guides/developer-and-contributor-notes.md) covers builds,
assets, debugging and repeatable in-game checks. Browse the
[API reference](xref:Rimgate) for Rimgate's public types and members, including
<xref:Rimgate.Building_Gate> and <xref:Rimgate.RimgateModSettings>.
Signatures and available XML comments are generated from the current build; the
guides explain how those features fit together.

## Current documentation

This site is built from `main` and follows the latest configured RimWorld target,
shown in the footer. It is not a versioned release archive. Rimgate is an open
source project used locally and has not been published as a mod release.
